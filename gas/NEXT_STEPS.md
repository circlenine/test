## 「設定」タブ（C011ver で追加）

スプレッドシートから直せる値の一覧。メニュー「🅰️ はじめの設定」→「⚙️ 設定タブを作る・直す」で作る。
C列（黄色）だけ触る。空にすると初期値に戻る。

| 項目 | 初期値 | 効くところ |
|---|---|---|
| ショートの上限（円） | 4,999 | 立ち回り分析の区分（002-Extras.gs） |
| ロングの下限（円） | 10,000 | 同上 |
| 営業曜日の始まり（時） | 17 | 日付の数え方すべて |
| オプチャ取込の開始時刻 | 17:00 | スクショ取込 |
| オプチャ取込の終了時刻 | 05:15 | スクショ取込 |
| オプチャの最低金額（円） | 1,000 | スクショ取込 |
| 要確認とみなす時刻の幅（分） | 15 | 身内の投稿の見分け |
| 高すぎる金額の線（円） | 40,000 | K列の ⚠️ |
| 裏メッセージの文面 | 📈{期間}レポート作成 byシバンニ | レポート送信（003-LineReport.gs） |

追加したいときは 001-Code.gs の `SETTINGS_DEFS` に1行足して、使うところを `cfg_("項目名")` に変える。
