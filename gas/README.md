# 売上レポート GAS

スプレッドシートの元データから、母集団の異なる2つのセクションを別々に出力する。

## セクション構成

| セクション | 内容 | 母集団 |
|---|---|---|
| 【自社実績】 | 平均売上・中央値・合計・区分別平均 | **A列が「オプチャ」または空白の行を除外** |
| 【大物マップ】 | 金額帯 × 区分 の件数分布 | **オプチャ行・空白行を含む全行** |

2つは母集団が違うので、同じ表に混ぜず必ず別セクションとして書き出す。
オプチャ経由は単価の振れ幅が大きく、自社実績の平均に混ぜると平均が壊れるため除外する。
一方で「どの金額帯に何件あるか」の分布はオプチャ込みで見たいので、そちらは全件を対象にする。

## 設定（`Code.gs` 冒頭の `CONFIG`）

実データに合わせて以下を調整すること。**現状の値は仮置き。**

| キー | 既定値 | 意味 |
|---|---|---|
| `SOURCE_SHEET` | `'データ'` | 元データのシート名 |
| `HEADER_ROW` | `1` | ヘッダー行 |
| `KUBUN_COL` | `1` | A列 = 区分/流入経路 |
| `SALES_HEADER` | `'売上'` | 売上金額の列ヘッダー名 |
| `OPUCHA_ALIASES` | `['オプチャ', 'オープンチャット', 'ｵﾌﾟﾁｬ']` | この語を含むA列の行をオプチャ判定（空白行は無条件でオプチャ） |
| `OPUCHA_LABEL` | `'オプチャ'` | 大物マップでオプチャ行＋空白行をまとめる列名 |
| `REPORT_SHEET` | `'レポート'` | 出力先シート名（毎回クリアして再生成） |
| `BUCKETS` | `[10万, 30万, 50万, 100万, 300万]` | 大物マップの金額帯の区切り |

### オプチャ判定

- **A列が空白の行はオプチャ扱い**（未記入＝オプチャ経由の運用のため）
- それ以外は NFKC 正規化＋空白除去の**部分一致**なので、「オプチャ経由」「ｵﾌﾟﾁｬ」などの表記ゆれも拾う

大物マップでは、空白行も明示「オプチャ」行も `OPUCHA_LABEL`（既定 `オプチャ`）の1列にまとめて計上する。

## 使い方

1. スプレッドシートの「拡張機能 → Apps Script」に `Code.gs` を貼る
2. `CONFIG` を実データに合わせる
3. シートを開き直すと「レポート」メニューが出る → 「レポートを生成」

## テスト

判定・パース・集計まわりの純粋関数を Node で検証する（SpreadsheetApp には依存しない）。

```
node gas/test/logic.test.js
```
